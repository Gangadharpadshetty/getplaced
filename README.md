# 🚀 GetPlaced — Career Guidance & Mentor Booking Platform

GetPlaced is a full-stack career guidance platform designed to help students connect with mentors, explore learning resources, and schedule mentorship sessions. The platform provides a clean UI experience for mentees to browse mentors, connect, and communicate effectively.

This project focuses on solving the common problem of **career confusion** by enabling students to find the right mentors based on skills, domain expertise, and hourly pricing.

---

## 🌟 Features

✅ Mentor Listing with profile cards  
✅ Mentor Pricing (₹/hr)  
✅ Mentor Rating display  
✅ Connect button to interact with mentors  
✅ Resources page for learning material  
✅ Contact page with working form UI  
✅ Authentication pages (Login / Signup)  
✅ Responsive UI with modern dark theme

## 🎯 Project Objective

The main goal of GetPlaced is to build a scalable platform where:

- Students can discover mentors easily
- Mentors can offer guidance sessions
- Users can book appointments
- Career resources can be accessed from one place
